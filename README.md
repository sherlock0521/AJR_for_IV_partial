# AJRforIV

This project replicates and analyzes part of the empirical strategy used in Acemoglu, Johnson, and Robinson (2001), *The Colonial Origins of Comparative Development*. The focus is on understanding the relationship between institutions and economic development using instrumental variable (IV) techniques.

## 📁 Project Summary

This is a course assignment for *Econometrics (II)*, focusing on:
- Estimating the effect of institutional quality (`avexpr`) on log GDP per capita (`logpgp95`)
- Addressing endogeneity via IV estimation using settler mortality (`logem4`)
- Applying the 2SLS method
- Performing a regression-based Hausman test

## 🔍 Key Variables

- `logpgp95`: Log of GDP per capita (1995)
- `avexpr`: Average expropriation risk (institutional quality measure)
- `logem4`: Log of settler mortality (instrumental variable)
- `africa`, `asia`, `other`: Regional dummy variables

## 🧪 Methods

1. **OLS regression** of `logpgp95` on `avexpr` and regional controls  
2. **2SLS regression** using `logem4` as an instrument for `avexpr`  
3. **Hausman test** to check for endogeneity of `avexpr`

## 📌 Notes

- This is a partial replication of AJR (2001), focusing on the baseline cross-country IV strategy.
- The analysis is based on the base sample (`baseco == 1`) provided in the dataset.
